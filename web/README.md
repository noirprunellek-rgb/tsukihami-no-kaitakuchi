# Web Prototype

`web/index.html` をブラウザで開くと、月喰みの漂流島の試作を遊べます。

## できること

- 4人/5人の正体と役職をランダム配布
- 全員が同じ海岸からスタート
- 24枚の六角島マップ表示
- 1ターン1マス移動
- パネル別アクション
- 橋、船修理、救難信号、脱出ルート、危険の管理
- 疑惑と孤立の管理
- 盤面コードのコピー/読み込み

## まだ簡略化していること

- 物資は個人手札ではなく共有在庫
- 隣接判定はプロトタイプ用の簡易判定
- 月喰みの妨害は手動で反映
- リアルタイム同期は未実装

## 次に足す候補

- Firebase無料枠による部屋ID同期
- 個人の物資手札
- 正確な六角マップ隣接
- 未踏パネルの裏向き探索
- 夜フェイズの秘密入力
