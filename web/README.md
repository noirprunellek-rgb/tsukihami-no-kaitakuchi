# Web Prototype

`web/index.html` をブラウザで開くと、月喰みの開拓地の同一画面用プロトタイプを遊べます。

## できること

- 4人/5人の正体と役職をランダム配布
- 各プレイヤーの正体確認
- 19枚の六角資源マップ表示
- 地形タイルへの開拓地/街の配置
- 夜フェイズ用の地形封鎖管理
- 朝、昼、投票、夜、状況確認の進行
- ダイスロール
- 勝利点、疑惑、弱体化、保護状態の管理
- 盤面コードのコピー/読み込み
- ログ表示

## オンライン化について

現在はGitHub Pagesで動く静的アプリです。共有タブの「盤面コード」を使うと、別端末に同じ盤面状態を渡せます。

リアルタイムで複数人が同じ卓に接続するには、次の段階でFirebase、Supabase、Cloudflare Workersなどの同期先を追加します。
