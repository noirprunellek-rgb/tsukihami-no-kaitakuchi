# 月喰みの漂流島

4-5人用、45-60分想定の協力サバイバル正体隠匿ゲームです。

プレイヤーたちは嵐で無人島に流れ着いた漂流者です。全員は同じ海岸から探索を始め、スコットランドヤード程度の広さを意識した大きめの島マップを移動しながら、脱出に必要な物資を集めます。

ただし、漂流者の中に1人だけ「月喰み」が紛れています。月喰みは正体を隠しながら、橋づくり、物資交換、救難信号、船の修理を邪魔します。

## プレイ概要

- 人数: 4-5人
- 時間: 45-60分
- ジャンル: 協力探索、サバイバル、正体隠匿、移動アクション
- 勝利形式: 陣営勝利

## 新しいゲームの核

以前の資源開拓・点取り型から、無人島脱出型へ変更しました。

村側は制限ターン内に協力して脱出条件を満たせば勝利します。月喰みは、物資を遠回りさせたり、橋を壊したり、夜の視界不良に紛れて危険地帯へ誘導したり、疑心暗鬼で協力を崩すことで勝利を狙います。

Web版はFirebase Realtime Databaseの無料枠を使った部屋同期に対応しています。Firebase設定を入れない場合でも、盤面コード共有で遊べます。
