# 月喰みの開拓地

カタン風の資源開拓に、人狼風の正体隠匿を組み合わせた 4-5 人用ボードゲーム企画です。

プレイヤーは未開の島「ルナヴァルト」で資源を集め、道・開拓地・街を建てて勝利点を伸ばします。ただし、開拓団の中には 1 人だけ呪いに取り込まれた「月喰み」が紛れています。

村側は開拓を進めながら月喰みを見つけることを目指します。月喰みは正体を隠し、妨害や誘導によって村人を誤って追放させます。追放されたプレイヤーは脱落せず、弱体化してゲームに残ります。

## プレイ概要

- 人数: 4-5 人
- 時間: 45-60 分
- ジャンル: 資源開拓、交渉、正体隠匿、投票
- 勝利形式: 陣営勝利

## このゲームの核

このゲームでは「疑うこと」自体が資源になります。

村側が正しく月喰みを追放できれば勝利に近づきますが、村人を誤追放すると、そのプレイヤーは交易・投票・役職能力を制限され、開拓団全体の生産力と交渉力が下がります。

月喰みは直接勝利点を伸ばすだけでなく、村に間違った追放をさせることで勝利に近づきます。
