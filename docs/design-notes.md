# デザインノート

## 目標体験

プレイヤーが「開拓を進めたいが、進め方が怪しく見える」という緊張を感じるゲームを目指します。

単に人狼を当てるゲームではなく、資源交渉、建設位置、投票誘導のすべてが推理材料になるようにします。

## 重要な設計方針

### 脱落させない追放

追放は脱落ではなく弱体化です。これにより、序盤に疑われたプレイヤーもゲームに参加し続けられます。

ただし、誤追放には明確な痛みが必要です。交易、投票、役職能力を失うことで、村側の開拓力が落ちます。

### 月喰みの勝ち筋を複数持たせる

月喰みは正体を隠すだけでなく、以下の複数の戦略を取れます。

- 自分の勝利点を伸ばして勝つ
- 村人を誤追放させて勝つ
- 村が目標点に届くまで一度も追放されずに勝つ
- 再追放を誘導して闇時計を進める

### 役職と正体を分ける

役職カードと正体カードを別にすることで、「強い役職を持っているから村側」とは言えなくなります。

月喰みが商人や測量士を持つと、むしろ自然に開拓へ貢献して白く見せられます。

## 初回テストで見ること

- 誤追放が本当に痛いか
- 月喰みが孤立せず、自然に会話へ混ざれるか
- 村側が開拓と推理の両方をする必要があるか
- 疑惑トークンが強すぎないか
- 45-60 分に収まるか

## 調整候補

- 村側の目標点
- 月喰み本人の勝利点条件
- 疑惑トークンの追加票条件
- 弱体化の重さ
- 占星術師の情報精度
- 番人の守れる対象
