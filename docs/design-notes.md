# デザインノート

## 方向転換

初期案のカタン風点取りは、正体隠匿と勝利点競争がぶつかり、村側の協力理由が弱くなりやすかった。

新案では、目的を「無人島からの協力脱出」に変更する。全員が同じ場所から始まり、移動、運搬、交換、橋づくり、修理、救難信号で協力する。

## 面白さの焦点

- 1ターン1マス移動なので、位置取りが重要になる
- 同じマスでしか交換できないため、合流する価値がある
- 川と橋がルート計画を作る
- 月喰みは大きな嘘より、小さな遅延で勝てる
- 誤った追放は孤立になり、運搬力と交換力を落とす

## 月喰みが楽しい理由

月喰みは「悪い行動」をしなくても邪魔できる。

- 重要物資を持って遠回りする
- 危険な洞窟探索を提案する
- 橋より救難信号を優先させる
- 合流を遅らせる
- 孤立投票を誘導する

## 初回テストで見ること

- 目標ターンが厳しすぎないか
- 川と橋が本当に悩ましいか
- 月喰みが露骨に見えすぎないか
- 同じマス交換が会話を生んでいるか
- 孤立が脱落より気持ちよく機能しているか
